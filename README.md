# 💰 Expense-Tracker-Python
# 

A simple **command-line Expense Tracker** built using Python.  
This project allows users to add expenses, view all recorded expenses, and calculate total spending.

---

## 📌 Project Overview

The Expense Tracker is a beginner-friendly Python project designed to manage daily expenses through a simple menu-driven command-line interface.

Users can:

- ➕ Add a new expense
- 📋 View all expenses
- 💰 Calculate total spending
- 🚪 Exit the application

Each expense is stored as a Python dictionary inside a list.

---

## 🚀 Features

### 1. Add Expense
Users can enter:

- 📅 Date
- 🏷️ Category
- 📝 Description
- 💵 Amount

Example categories:

- Food
- Travel
- Makeup
- Books

---

### 2. View All Expenses

Displays all expenses entered by the user along with:

- Date
- Category
- Description
- Amount

---

### 3. View Total Spending

The application calculates and displays the total amount spent across all recorded expenses.

---

### 4. Exit

Users can exit the Expense Tracker through the menu.
